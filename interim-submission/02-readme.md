# Финни

Детская игра-тамагочи по финансовой грамотности для детей 7–11 лет. Функциональный прототип для Android, конкурсная работа для Департамента финансов города Москвы.

Ребёнок заводит питомца и выходит с ним на «смены». Смена — это урок, за который платят зарплату. До начала смены ребёнок планирует бюджет: сколько потратить и сколько отложить. Во время урока он решает, на что тратить (нужное, желаемое или бесплатная альтернатива), а в конце видит план и факт. Отложенное уходит в «Копилку» на цель — улучшение комнаты питомца. За пройденные уроки растёт уровень, и питомец получает новые облики.

Регистрации и персональных данных нет, рекламы и реальных платежей тоже. Приложение работает полностью офлайн.

## Быстрый запуск

### Без установки: веб-прототип

https://lugertr.github.io/fin-pet/ — открыть в Chrome, лучше в окне шириной с телефон. Данные хранятся в браузере. Веб-версия служит для предварительного просмотра, целевая платформа — Android.

### Из исходников

Нужны Node.js 20+ (проверено на 24.11) и npm.

```bash
npm install
npx expo start      # затем a — Android-эмулятор или Expo Go на телефоне, w — браузер
```

### Проверки

```bash
npm test                  # автотесты (Jest)
npx tsc --noEmit          # проверка типов
npx eslint src scripts    # линтер исходников
npm run lessons:check     # хватает ли денег смены на каждый урок в худшем случае
```

## Демо-режим для экспертов

Цикл от создания питомца до нового уровня проходится за 1–2 минуты, без ожидания реального времени.

1. На первом экране включить **«Режим демонстрации»** и пройти знакомство: три типа решений, питомец, облик, имя, первая цель.
2. На главном экране нажать **«Начать смену»**, выбрать тему («Бюджет») и разделить зарплату.
3. На экране смены пройти задания урока (тест, событие с тратой). Быстрый путь — кнопка **«Завершить урок (демо)»**.
4. На главном экране появятся итоги смены (план и факт, перенос в копилку) и окно «Опыт и уровень». Кнопка «Новая смена» начинает следующий период.
5. Кнопка **«+1 день»** на главном экране проматывает сутки для ежедневной награды.
6. Во вкладке «Копилка» можно выбрать цель, пополнить накопления и снять монеты.

Демо-режим для уже созданного профиля включается в «Прогресс → Родителям» (PIN) переключателем «Демо-режим». Кнопка **«Начать демо заново»** там же удаляет демо-профиль и открывает знакомство заново.

## Сброс и удаление профиля

«Прогресс → Родителям» (вход по PIN). **Сбросить профиль** возвращает экономику и прогресс к исходным, имя и питомец остаются. **Удалить профиль** полностью стирает локальные данные. Оба действия требуют подтверждения.

## Известные ограничения прототипа

- Release-APK ещё не собран; проверки на физическом устройстве не было.
- ИИ-помощник есть в коде как локальная заглушка, но скрыт из интерфейса. В обязательный сценарий не входит.
- Веб-версия хранит данные в браузере. Одновременно приложение может быть открыто только в одной вкладке.
