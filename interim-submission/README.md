## Коротко о состоянии

- **Работает:** знакомство с тремя типами решений, создание питомца (9 комбинаций), главный экран, смена как игровой период (план → урок с событиями → итоги план/факт → выплата), копилка с целью, магазин, 37 уроков в 7 темах, уровни и облики, раздел для взрослого с PIN, демо-режим, сохранение между запусками, полный офлайн, 413 автотестов.
- **Главные пробелы по ТЗ:** план по двум направлениям вместо трёх; в магазине нет обязательных покупок, а при нехватке монет нет объяснения; рост питомца зависит от уроков, а не от финансовых решений; на главном экране нет накоплений и цели; нет пояснений после ответов в тестах и после выбора в событиях.
- **Сборка:** release-APK ещё не собирался; требуется задать имя пакета, иконку и убрать лишние разрешения.
