# Разбор для команды (не для отправки экспертам)

Сверка текущего кода (ветка `new-adventure`, 29.09.2026) с присланными разделами ТЗ Департамента: требования к промежуточной сдаче, критерии оценки 8.1–8.4, раздел 2.5, Приложение А. По правилу из `CLAUDE.md` («конфликт не решай молча») ниже перечислены все найденные расхождения. Код и существующие файлы не менялись.

## 1. Главное

1. **Четыре требования раздела 2.5 не закрыты по сути, и все они видны в сквозном сценарии:** план по трём направлениям (шаг 5), обязательные покупки и нехватка средств (шаг 7), рост питомца от финансовых решений (шаг 10), главный экран без накоплений и цели (шаг 4). В большинстве случаев это прямые последствия решений команды от 27–29.09 — см. раздел 2.
2. **APK нет, и сборка не готова:** не задано имя пакета, нет иконки, в манифест попадёт микрофон (`RECORD_AUDIO`) — см. `03-apk-prototype-video.md`.
3. **Проверки экспертов сейчас «красные»:** `npm test` — 1 падение, `npm run lessons:check` — 16 уроков с нехваткой денег, `npm run lint` — 8257 ошибок из собранного `docs/`.
4. **По ссылке на репозиторий эксперты увидят старую версию:** ветка по умолчанию — `master` (`2a7e401`). Pages при этом уже отдаёт `new-adventure`.
5. **Сильные стороны:** слои разделены, 413 тестов доменной логики, версионируемые миграции, транзакция при завершении смены, полный офлайн, нет секретов и персональных данных, контент в JSON с проверками, демо-режим, подсказка «?» на каждом экране.
