## Интерактивный прототип

- Ссылка: https://lugertr.github.io/fin-pet/. Лучше открывать в Chrome, в окне шириной с телефон (или DevTools → режим устройства, 390×844).
- На первом экране есть переключатель «Режим демонстрации»: с ним весь цикл проходится за 1–2 минуты.
- Ограничения веб-версии. Данные хранятся в браузере, поэтому очистка данных сайта сбрасывает профиль. Приложение можно открыть только в одной вкладке. Вибрации нет. Целевая платформа — Android, веб служит только для просмотра.
- Сборка веб-версии: `npm run build:docs` (кладёт результат в `docs/`).

## Подготовка к сборке: что поправить в `app.json`

Правки вносит команда; в рамках анализа файл не менялся. Сейчас конфигурация даёт сборку с названием «fin-pet», иконкой Expo по умолчанию и лишними разрешениями.

| №   | Что                                            | Сейчас                                                            | Нужно                                                                                     |
| --- | ---------------------------------------------- | ----------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 1   | Название под иконкой                           | `"name": "fin-pet"`                                               | `"name": "Финни"`                                                                         |
| 2   | Имя пакета (требование 3.3 — уникальное)       | не задано (`npx expo config` подставляет `com.placeholder.appid`) | например `ru.<команда>.finni`. После публикации его менять нельзя                         |
| 3   | Версия и номер сборки (указать в документации) | `"version": "1.0.0"`, номера сборки нет                           | `version` + `android.versionCode: 1`                                                      |
| 4   | Иконка                                         | нет (`assets/expo.icon` — только для iOS)                         | `icon` 1024×1024 и `android.adaptiveIcon`; из того же макета — иконка 512×512 для RuStore |
| 5   | Ориентация (требование 3.1.2 — портрет)        | не зафиксирована                                                  | `"orientation": "portrait"`                                                               |
| 6   | Разрешения (требования 3.1.4 и 3.4)            | см. ниже                                                          | заблокировать лишнее, остальное обосновать                                                |

### Какие разрешения попадут в APK без правок

Состав получен командой `npx expo config --type introspect` и из манифестов подключённых библиотек. Окончательный список проверяется на собранном APK: `aapt dump permissions app-release.apk`.

| Разрешение                                                | Откуда                                             | Нужно ли                                                                                                                 | Решение                                                    |
| --------------------------------------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------- |
| `RECORD_AUDIO` (микрофон)                                 | плагин `expo-audio`, значение по умолчанию         | Нет, запись звука не используется                                                                                        | Отключить: `recordAudioAndroid: false`                     |
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_MEDIA_PLAYBACK` | `expo-audio`, фоновое воспроизведение по умолчанию | Нет                                                                                                                      | `enableBackgroundPlayback: false`                          |
| `READ_EXTERNAL_STORAGE`, `WRITE_EXTERNAL_STORAGE`         | шаблон Expo, `expo-file-system`, `expo-image`      | Нет                                                                                                                      | `blockedPermissions`                                       |
| `SYSTEM_ALERT_WINDOW`                                     | шаблон Expo                                        | Нет                                                                                                                      | `blockedPermissions`                                       |
| `POST_NOTIFICATIONS`, `RECEIVE_BOOT_COMPLETED`            | `expo-notifications`                               | Только если оставить напоминания. Сейчас на Android 13+ запрос разрешения появляется при первом открытии главного экрана | Решение команды — см. `team-notes.md` и вопрос 7.10        |
| `VIBRATE`                                                 | `expo-haptics`                                     | Да, тактильный отклик (отключается в настройках)                                                                         | Оставить, обосновать                                       |
| `MODIFY_AUDIO_SETTINGS`                                   | `expo-audio`                                       | Да, звуки интерфейса (отключаются в настройках)                                                                          | Оставить, обосновать                                       |
| `INTERNET`, `ACCESS_NETWORK_STATE`                        | React Native, `expo-image`                         | Приложение в сеть не ходит                                                                                               | Оставить с пояснением или заблокировать и проверить сборку |

Пример фрагмента `app.json`:

```json
{
  "expo": {
    "name": "Финни",
    "version": "1.0.0",
    "orientation": "portrait",
    "icon": "./assets/icon.png",
    "android": {
      "package": "ru.example.finni",
      "versionCode": 1,
      "adaptiveIcon": {
        "foregroundImage": "./assets/adaptive-icon.png",
        "backgroundColor": "#101828"
      },
      "blockedPermissions": [
        "android.permission.RECORD_AUDIO",
        "android.permission.READ_EXTERNAL_STORAGE",
        "android.permission.WRITE_EXTERNAL_STORAGE",
        "android.permission.SYSTEM_ALERT_WINDOW"
      ]
    },
    "plugins": [
      [
        "expo-audio",
        {
          "recordAudioAndroid": false,
          "enableBackgroundPlayback": false,
          "microphonePermission": false
        }
      ]
    ]
  }
}
```

(Остальные плагины — `expo-router`, `expo-build-properties`, `expo-sqlite` — остаются как есть. Файлов иконок в проекте пока нет, пути в примере условные.)

## Вариант А: облачная сборка EAS (быстрее всего)

```bash
npm install -g eas-cli
eas login                     # учётная запись Expo команды
eas build:configure           # создаст eas.json
```

Профиль для APK в `eas.json`:

```json
{
  "build": {
    "apk": { "distribution": "internal", "android": { "buildType": "apk" } },
    "production": { "android": { "buildType": "app-bundle" } }
  }
}
```

```bash
eas build -p android --profile apk        # подписанный APK
eas build -p android --profile production # AAB (по желанию)
```

EAS сам создаёт ключ подписи и хранит его в учётной записи Expo; в репозиторий ключ не попадает. Копию можно скачать через `eas credentials`. Учтите, что исходники при этом загружаются на серверы Expo. Для воспроизводимости в документации стоит описать и локальную сборку.

## Вариант Б: локальная сборка

Окружение: Node.js 20+, JDK 17, Android SDK Platform 36, Build-Tools 36.0.0, NDK 27.1.12297006 (версии заданы в `react-native` 0.86.3; `minSdk` 24 покрывает Android 8.0+).

```bash
npx expo prebuild -p android --clean     # создаёт android/ (папка в .gitignore)
keytool -genkeypair -v -storetype PKCS12 -keystore finni-release.jks \
  -alias finni -keyalg RSA -keysize 2048 -validity 10000     # ключ хранить ВНЕ репозитория
```

Важно: в проекте после `prebuild` release-сборка по умолчанию подписывается **отладочным** ключом. Для сдачи нужно добавить `signingConfigs.release` в `android/app/build.gradle`, а пароли брать из `~/.gradle/gradle.properties` или переменных окружения. Поскольку `prebuild --clean` пересоздаёт `android/`, этот шаг надо либо описать в README, либо оформить конфиг-плагином.

```bash
cd android
./gradlew assembleRelease     # → android/app/build/outputs/apk/release/app-release.apk
./gradlew bundleRelease       # → AAB (по желанию)
apksigner verify --print-certs app/build/outputs/apk/release/app-release.apk
```

## Установка и проверка на устройстве

1. `adb install -r app-release.apk` или передать файл на телефон и открыть его (разрешить установку из неизвестных источников).
2. Требования 3.1 и 3.4: Android 8.0+, портрет, экран от 360 dp, физическое устройство с RAM от 3 ГБ.
3. Холодный старт до главного экрана — не дольше 5 с: `adb shell am start -W -n <package>/.MainActivity`, поле `TotalTime`.
4. Отклик на действия — не дольше 1 с; пройти сценарий Приложения А без падений и тупиков. Результаты записать в отчёт о проверке (обязательный документ финала).

## Видео текущего сценария (до 3 минут)

Записывать с Android-устройства: встроенная «Запись экрана» или `scrcpy --record finni.mp4` с компьютера. Включить «Не беспокоить», чтобы личные уведомления не попали в кадр. До появления APK можно записать веб-прототип (Chrome, режим устройства 390×844) и подписать ролик как «веб-прототип».

Профиль — демонстрационный (переключатель на первом экране).

Что в текущей версии показать не получится (исправления — в плане, `06-requirements-matrix.md`):

- **Шаг 5.** Распределение идёт по двум направлениям, а не по трём.
- **Шаг 7, «нехватка средств».** В демо-профиле магазин бесплатный. В обычном профиле кнопка «Нет монет» неактивна, поэтому окно «Не хватает N C» не открывается. Обязательных товаров в магазине нет: обязательные траты есть только в событиях уроков.
- **Шаг 10.** Уровень растёт за пройденный урок, а не за серию финансовых решений.
