## 4. Локальный профиль и авторизация

### 4.1 Концепция

Приложение работает полностью локально по умолчанию. Профиль = игровое имя питомца + внешний вид. Регистрация и персональные данные не требуются.

### 4.2 Модель профиля

```
LocalProfile {
    id: UUID
    pet_name: String              // 2–15 символов
    pet_type: "robot"|"bear"|"cat"
    pet_appearance: { color_variant: Int }   // 0 — встроенный вид, 1–2 — скины
    created_at: Timestamp
    is_demo: Boolean = false
}
```

### 4.3 Визуальные комбинации

Минимум 9 (3 типа × 3 цвета). **⚠ Сейчас 7:** у робота и кота по 3 вида (базовый + 2 скина), у мишки — только базовый (нет арта и товаров-скинов для вариантов 1–2). См. §30.

### 4.4 Онбординг

```
1. Знакомство: цель игры
2. Три типа решений — нужное / желаемое / отложить
3. Выбор питомца: робот, мишка, кот
4. Облик (любой из трёх: классический или один из двух цветных) и имя питомца (2–15 символов); два других облика придут на уровнях 2 и 3
5. Стартовый капитал: 100 монет (50 кошелёк + 50 накопления), базовая комната
```

Выбор компетенции на онбординге исключён: ветка обучения выбирается заново в начале каждого приключения (§7).

### 4.5 Сохранение состояния

Данные сохраняются после каждого действия. При закрытии/перезапуске — полное восстановление, включая идущее приключение (его таймер тикает и при закрытом приложении). Удаление — только из раздела для взрослого (§17). Потеря прогресса не допускается.

### 4.6 Серверная авторизация — вне MVP

```
Флаг: online_auth = false (по умолчанию)
При активации в будущем: гибридная авторизация (device_id + email/пароль), JWT, синхронизация прогресса.
```

## 6. Энергия

### 6.1 Параметры

| Параметр         | Значение                                        |
| ---------------- | ----------------------------------------------- |
| Базовый максимум | 100⚡                                           |
| Бонусы           | Кровать: +15…+25⚡ к максимуму                  |
| Восстановление   | +12,5⚡/час (полное за 8 часов)                 |
| Отображение      | Число ⚡ в общей шапке на всех экранах           |

### 6.2 Расходы энергии

| Действие                   | Стоимость                                                                      |
| -------------------------- | ------------------------------------------------------------------------------ |
| Уроки (в т.ч. повтор)      | Бесплатно; только в задании приключения (§7.5) неверный ответ — 5⚡             |
| Тренажёры (Аркада)         | 10⚡ за игру                                                                    |
| ИИ-помощник                | 5⚡ (до 2⚡ с предметом «облако» — таких товаров пока нет, §12.2)                |
| Покупки, открытие подарков | Бесплатно                                                                      |

Штраф за неверный ответ внутри задания приключения — единственное согласованное отступление от общего правила «ошибка не наказывается» (§2); вне приключения и при повторе урока штраф не действует.

### 6.3 Формула восстановления

```
current_energy = min(100 + decor_max_bonus,
                      stored_energy + hours_passed × (12.5 + decor_recovery_bonus))
```

### 6.4 Энергия и обязательные расходы

Еда — обязательная категория товаров (§12.2) и вынужденная мера: купить и съесть её можно, только когда питомец голоден (энергия < 30⚡); сытому питомцу — объяснение, что энергия восстанавливается сама. Цена еды — не ниже 10 монет за 1⚡ (+5…+25⚡), поэтому «еда → энергия → Аркада» не приносит выгоды (Аркада даёт максимум 2 монеты за 1⚡). Низкая энергия не блокирует уроки, бюджет, покупки, накопления, переход между приключениями (§7) — только Аркаду и ИИ-помощника (с объяснением «покорми питомца или подожди»). **⚠** Отдельной подсказки на главном экране «питомец голоден — купи еду» нет — см. §30.

## 7. Приключение: обучение и планирование бюджета

### 7.1 Концепция

«Приключение» объединяет планирование бюджета и прохождение уроков в один цикл — заменяет собой более раннюю модель «игровой период». Приключение привязано к реальному времени (не к календарным дням, кроме ежедневного стрика §5) и к одной выбранной на старте компетенции (ветке обучения, §9.2). Начинается тапом по ноутбуку в комнате питомца или кнопкой «Начать приключение» на главном экране («Продолжить планирование», если план ещё не подтверждён).

Хаб остаётся хабом и во время приключения; экран приключения — отдельный, открывается кнопкой «Продолжить приключение» (с оставшимся временем) или тапом по ноутбуку. В его шапке слева — «назад» на хаб, справа рядом с монетами и энергией — «?» и ✕ (завершить досрочно). Когда приключение завершено, экран сам возвращает на хаб, где показываются итоги.

### 7.2 Структура приключения

```
ПЛАНИРОВАНИЕ:
  1. Бюджет приключения (100 C) делится на «Потратить» и «Коплю» (§7.3, ⚠ §30 п. 9)
  2. Выбор одной из компетенций (§9.2); ветка, пройденная на 100%, подсвечивается и
     требует подтверждения выбора — задания в ней идут через Аркаду (§10), а не уроки
  3. Подтверждение плана → доход становится бюджетом приключения (не кошельком
     хаба), приключение переходит в активную фазу, таймер ставится на 8 часов
АКТИВНАЯ ФАЗА (8 реальных часов; тикает и при закрытом приложении):
  - Экран: сцена с питомцем; полоска прогресса с оставшимся временем и бюджетом
    приключения; кнопка «Выполнить задание» и рядом вход в Аркаду; тема текущего
    урока; карточки «План» (надо / хочу / коплю: план и факт) и «Банк» хаба
    (прогресс к цели); ✕ слева сверху — завершить
  - Задание — следующий урок выбранной ветки (либо раунд Аркады по ней же, если
    ветка уже пройдена, §7.5): сокращает оставшееся время; монеты за урок — сразу
    в кошелёк хаба
  - Случайные события (§7.6): тратят и пополняют бюджет приключения; не
    останавливают прогресс, но не дают завершить приключение, пока не решены
  - Магазин и «Банк» — контур хаба: покупки и пополнения бюджет и факт
    приключения не меняют
ЗАВЕРШЕНИЕ:
  - Автоматически, когда время вышло (при запуске приложения или на вкладке
    приключения); нерешённое событие при этом снимается без последствий
  - Вручную — ✕ с подтверждением; до истечения времени награда пропорциональна
    прошедшей доле времени (не штраф, а выбор ребёнка)
  - план vs факт (§7.4) → бонус за план в бюджет (§5) → выплата остатка бюджета в
    хаб: «коплю» — в банк, остальное — в кошелёк → опыт игроку (150), возможен
    переход на новый уровень (§8.2) → итоги модалкой на вернувшемся главном
    экране → следующее приключение (новое планирование)
ДЕМО-РЕЖИМ (§18): приключение можно завершить в любой момент с полной наградой,
  события — при каждом заходе на экран, каждое приключение — новый уровень
```

### 7.3 Планирование бюджета

До начала активной фазы — распределение бюджета этого приключения (100 монет) на две категории (решение 27.09). В каждом поле заливка и подпись «N%» показывают долю бюджета:

| Категория | Описание                    |
| --------- | --------------------------- |
| Потратить | Траты событий приключения — и на нужное («надо»), и на желаемое («хочу») |
| Коплю     | В конце приключения уходит в банк хаба — на финансовую цель |

**⚠** «Надо» и «Хочу» не планируются отдельно — они видны только в факте трат (каждый платный вариант события помечен нужным или желаемым). См. §30 п. 9.

Правила: сумма ≤ бюджет приключения; нераспределённый остаток виден в реальном времени; план редактируется до подтверждения; после подтверждения — база для сравнения с фактом, доход становится бюджетом приключения.

### 7.4 Сравнение плана с фактом

Во время приключения — кнопка «План» открывает модалку по центру экрана (фиксированной ширины): бюджет приключения, «Потратить» — потрачено из запланированного (и из них на нужное / желаемое), «Коплю» — сколько уйдёт в банк, число выполненных заданий. Карточки «Банк» в приключении нет — банк открывается только на хабе (копилка).

По завершении — итоги: «Потратить» — потрачено / по плану (факт с разбивкой на нужное и желаемое), «Коплю» — сколько ушло в банк (и бонус банка), остаток — в кошелёк, бонус за план (если факт трат ≤ плана), опыт, новый уровень. Если потрачено больше плана, в банк уходит то, что осталось. **⚠** Колонки «разница» и нейтрального комментария питомца нет — см. §30.

### 7.5 Задания и итоговый результат

Задание = прохождение следующего непройденного урока выбранной ветки (§9); если ветка уже пройдена на 100%, тем же заданием становится раунд Аркады (§10) по ней же. Каждое выполненное задание:

- сокращает оставшееся время на 45 минут (таймер не опускается ниже 15 минут и никогда не продлевается заданием);
- приносит монеты за урок сразу в кошелёк хаба (не в бюджет приключения; +10% за урок-задание и процент ноутбука, §9.3);
- опыта само не даёт — опыт только за завершение приключения (§8.2);
- неверный ответ в задании стоит 5⚡ (§6.2).

Повтор уже пройденного урока заданием не считается (§9.7).

### 7.6 Случайные события

Модальное окно с 2–3 вариантами выбора (контент — в `content/adventure_events.json`, отделён от кода, §25; шесть шаблонов). Все деньги событий — из бюджета приключения (он показан в окне): потратить на «надо» (обычно ускоряет приключение) или на «хочу» (обновки и развлечения; предметов и скинов события не выдают), получить небольшую награду в бюджет, изменить оставшееся время. Суммы и время рисуются из данных, не из текста подписи.

Ритм (одно событие за раз, следующее — только после решения текущего):

| Правило                                   | Значение                                                        |
| ----------------------------------------- | --------------------------------------------------------------- |
| Первое событие                            | Не раньше 5 минут после старта                                  |
| Обычный интервал                          | ~60 минут после предыдущего                                     |
| При заходе на экран приключения           | Уже через 30 минут, если энергия > 20, в бюджете приключения ≥ 20% его дохода, план трат не исчерпан и до конца ≥ 1 часа |
| Конец приключения                         | Не появляются за 20 минут до конца и после него                 |
| Лимит                                     | Не больше 6 за приключение, шаблоны не повторяются              |
| Проверка                                  | Только пока экран приключения открыт (не поверх урока)          |

Правила вариантов: трата никогда не уводит бюджет в минус — платный вариант, на который не хватает бюджета, недоступен с подписью «Не хватает N монет» (§12.3); в каждом событии есть бесплатный вариант. Отказ от выбора (закрыть окно) не наказывается и не мешает выполнять задания — только блокирует ручное завершение до решения.

## 8. Состояние и рост питомца

### 8.1 Состояние

Единственный текущий показатель — энергия (§6), показывается числом ⚡ в общей шапке (отдельная полоска на главном экране убрана как дублирующая). Визуальные состояния питомца: обычный (энергия > 20) и спящий (≤ 20). **⚠** ТЗ предусматривает 4 диапазона (радость / обычный / усталый / голодный) — сейчас их 2, см. §30. Смерти, болезни, травмы нет.

### 8.2 Рост: уровень и опыт игрока

Рост измеряется опытом игрока. Опыт даёт только завершение приключения — фиксированно, независимо от числа заданий (уроки и задания приносят монеты, §5):

| Источник опыта         | Опыт |
| ---------------------- | ---- |
| Завершение приключения | +150 |

При досрочном завершении приключения всё, что оно даёт, пропорционально пройденной доле времени (закрыто на 10% — 10%): опыт, бонус за план, выплата остатка бюджета и «коплю» (невыплаченная часть не переносится); бонус банка на «коплю» при этом не начисляется. Так «начал и сразу закрыл» не приносит бюджет приключения. В демо-режиме — полная награда.

```
PlayerLevel {
    total_xp: Int = 0
    level: Int = 1   // 1–10, не уменьшается
}
```

Порог следующего уровня растёт линейно: `xp_for_level(level) = 250 × level` (уровень 2 — 250 опыта, уровень 3 — 750).

### 8.3 Таблица уровней (званий)

| Уровень | Звание             | Награда                       |
| ------- | ------------------ | ----------------------------- |
| 1       | Стажёр             | —                             |
| 2       | Ученик Финансов    | 100 монет + новый облик       |
| 3       | Практикант         | 150 монет + новый облик       |
| 4       | Финансовый Скаут   | 200 монет                     |
| 5       | Финансовый Агент   | 250 монет                     |
| 6       | Финансовый Стратег | 300 монет                     |
| 7       | Финансовый Эксперт | 350 монет                     |
| 8       | Финансовый Мастер  | 400 монет                     |
| 9       | Финансовый Гуру    | 500 монет                     |
| 10      | Финансовый Чемпион | 750 монет + редкий декор      |

Облик на уровнях 2 и 3 — тот, которого у ребёнка ещё нет: при создании выбирается любой из трёх обликов своего вида (классический тоже предмет в инвентаре), два остальных приходят на этих уровнях — сначала цветные (сразу надеваются), классический последним (появляется в инвентаре). Облики не продаются и не выдаются иначе (§12.2). **⚠** Для мишки скинов в каталоге нет (§4.3) — на этих уровнях он получает только монеты.

Уровень 2 — после 2 приключений, уровень 3 (со скином) — ровно после 5 (5 × 150 = 750 опыта), то есть в пределах минимума демо-приключений (§20). В демо-режиме каждое приключение даёт новый уровень (§18.2).

### 8.4 Правила роста

Уровень не уменьшается. Продажа предметов инвентаря на него не влияет. При переходе — анимация и объяснение, какая награда получена (монеты и/или скин).

## 9. Обучение

### 9.1 Иерархия

```
Ветка → Урок (группировки «уровень» в контенте нет — «завершение уровня» в §14.1
            засчитывается по завершению урока)
Урок: теория (карточки) → мини-игра (если есть) → тест → одна награда в конце
```

У урока-викторины (мини-игра «Викторина») вопросы мини-игры и теста — одна пачка: сначала вопросы мини-игры, затем теста, одинаковые по тексту — один раз (⚠ §30 п. 12). Уроки со «Свайпами» и «5 букв» — с отдельным шагом мини-игры.

### 9.2 Ветки

Требование ТЗ Департамента — задания минимум по 3 темам: планирование бюджета; формирование сбережений; платежи и покупки (+ дополнительная «Финансовая безопасность»). Компетенция об участии значимого взрослого закрывается разделом для взрослого (§17), а не отдельным уроком.

Текущий контент: 7 веток, 19 уроков для 7–11 лет; обязательные темы — первыми. Короткие названия веток — для вкладок и матрицы компетенций, тема ТЗ — в описании ветки.

| ---------- | ----------------- | --------- |

| Мини-игра  | 25 монет          | Бесплатно |
| Тест       | 50 монет          | Бесплатно |

Награда одна — сумма за пройденные фазы в конце урока (60–85 монет), сразу в кошелёк хаба — и за обычный урок, и за урок-задание приключения. Повтор — без награды (§9.7). Ноутбук увеличивает награду на свой процент (§12.2), задание приключения — ещё на 10%. Опыта уроки не дают (§8.2).

### 9.4 Мини-игры

| Тип          | Механика                   | Вопросов |
| ------------ | -------------------------- | -------- |
| quiz         | Выбор из 3–4 вариантов     | по уроку |
| tinder_swipe | Свайп влево/вправо         | по уроку |
| five_letters | Угадать слово из 5 букв    | 1 слово  |

Жизней нет; ошибка — свободный повтор, без штрафа. Исключение: пока урок проходится как задание активного приключения (§7.5), неверный ответ дополнительно тратит 5⚡ энергии (§6.2).

### 9.5 Итоговый тест

5 вопросов, порог 70% (4/5); у урока-викторины в той же пачке первыми идут 1–2 вопроса мини-игры (6–7 вопросов, порог тот же — 70%). Сдал → переход к награде. Не сдал → повтор без штрафа.

### 9.6 Распределение дохода

Отдельного распределения после каждого урока нет: награда за урок зачисляется в кошелёк хаба, а распределение дохода на надо / хочу / коплю происходит при планировании приключения (§7.3); в хабе — пополнением «Банка» (§11).

### 9.7 Доступность уроков

- Новые уроки проходятся как задания приключения — по порядку внутри выбранной ветки (кнопка «Выполнить задание»).
- Пройденный урок доступен для повтора без награды (с вкладки «Уроки» или по ссылке ИИ-помощника).
- В демо-режиме любой урок открывается сразу и проходится в укороченном виде (§18.2).
- Попытка открыть новый урок вне этих правил — объяснение, где его пройти.

## 10. Тренажёры (Аркада)

### 10.1 Концепция

Тренировка по теме (компетенции) текущего приключения. Тратит энергию. Не ограничено по числу прохождений. Открывается с экрана приключения (кнопка рядом с «Выполнить задание»); на главном экране входа нет. Ребёнок выбирает любую мини-игру темы: «Викторина», «Свайпы» или «5 букв». Раунд, выбранный в Аркаде, — тренировка: он приближает финиш приключения, но слабее урока — до 15 минут пропорционально доле верных ответов (урок-задание — 45 минут) и заданием не считается. У каждой мини-игры своя подсказка «?» — как в неё играть (и в Аркаде, и в уроке на шаге мини-игры). Для веток, уже пройденных на 100%, Аркада служит и заданием приключения (§7.5): кнопка задания запускает раунд случайной игры этой темы, и он засчитывается как задание.

### 10.2 Параметры

| Параметр    | Значение                   |
| ----------- | -------------------------- |
| Стоимость   | 10⚡ за игру               |
| Награда     | +2 монеты за правильный ответ (было +10; снижено 27.09.2026, иначе полная энергия в Аркаде давала до 1000 монет за 8 часов и улучшения покупались без банка) |
| Доступность | Тема текущего приключения (⚠ §30 п. 10) |
| Подарки     | Не выпадают                |

### 10.3 Логика выбора контента

Тема приключения → выбранная ребёнком игра → пул контента темы → перемешать и обрезать:

| Игра       | Контент темы                                                        | В раунде   |
| ---------- | ------------------------------------------------------------------- | ---------- |
| Викторина  | вопросы мини-игр-квизов и итоговых тестов уроков темы               | до 10      |
| Свайпы     | свайпы из уроков темы + `content/arcade_swipe_cards.json`           | до 5       |
| 5 букв     | слова `content/five_letters_words.json` с этой темой в `branch_ids` | до 3 слов  |

Контент есть для всех трёх игр в каждой из 7 тем (проверяется тестом). Настройки «исключить тему из тренировки» больше нет — тема задаётся приключением.

## 11. Накопления и финансовая цель

### 11.1 Параметры

| Параметр               | Значение                                                       |
| ---------------------- | -------------------------------------------------------------- |
| Бонус                  | Фиксированный, небольшой (база 1%), не растёт со временем      |
| Начисление             | При пополнении, не фоновой задачей                             |
| Влияние на прохождение | Не требуется для обязательного сценария                        |

### 11.2 Цель = улучшение ключевой вещи

Цель накоплений — улучшение одной из трёх вещей с бонусами: ноутбука, копилки или кровати (§12.2). Первую цель ребёнок выбирает в онбординге (ближайшее улучшение каждой из трёх вещей), сменить её можно в «Копилке» теми же карточками.

### 11.3 Механика цели

Выбор предмета → «Копить на это» → прогресс-бар во вкладке «Копилка» (туда же ведёт копилка в комнате) → пополнения (из кошелька и «коплю» из каждого завершённого приключения) → накоплено ≥ цены → покупка → предмет в инвентаре.

### 11.4 Формула бонуса

```
returned  = min(deposit, withdrawal_credit)   // возврат ранее снятого
new_money = deposit − returned
bonus     = floor(new_money × bonus_rate / 100)
```

Бонус начисляется только за новые деньги: пополнение сначала «гасит» ранее снятое из банка (withdrawal_credit), на возврат своих же монет бонус не начисляется; «коплю» из приключения — новые деньги целиком. Поэтому ни пополнения по 1 монете, ни «снял — положил обратно» дохода не дают. `bonus_rate` — фиксированное небольшое значение (1%), не увеличивается со временем. Увеличивается только бонусами предметов-копилок (+2…+4, §12.2). Не является имитацией банковского вклада.

### 11.5 Награды за удержание

| Условие                          | Награда                                 |
| -------------------------------- | --------------------------------------- |
| Достижение цели                  | Предмет цели + 10% его цены монетами    |

Подарков за банк нет — подарок дают только за 7 дней подряд (§14).

### 11.6 Модель данных

```
Savings { id, current_amount: Int = 0, bonus_rate: Float, target_item_id: Int?, periods_since_withdrawal: Int = 0, withdrawal_credit: Int = 0 }
SavingsTransaction { id, operation_type: "deposit"|"withdraw"|"bonus"|"reward", amount, balance_after, period_id, created_at }
// period_id — историческое имя поля, хранит id приключения
```

Перед покупкой: цена, категория, влияние на питомца. Требует подтверждения. Отрицательный баланс не допускается; при нехватке — объяснение («не хватает N монет») и вариант действия («К приключению» — заработать). Магазин — контур хаба: покупки во время приключения его бюджет и факт не меняют.

| Скрытые предметы (§14)    | Нет     | —        |

## 16. ИИ-помощник

### 16.1 Архитектура

Целевая архитектура — небольшая локальная ИИ-модель, работающая полностью на устройстве (on-device inference): интернет и сервер не требуются. Датасет: ≈1000 пар вопрос–ответ по финансовой грамотности + база знаний, соответствующая содержанию веток обучения (§9). Конкретная реализация — на усмотрение команды при соблюдении §16.3.

**Текущее состояние:** ответ даёт локальная заглушка `StubAiAssistant` (фиксированные ответы по ключевым темам из `content/ai_stub_responses.json` со ссылкой на урок) за интерфейсом `AiAssistant` — модель подменяется без переработки экрана. Списание энергии, история, очистка истории работают по-настоящему. Ссылка на урок подчиняется правилам доступа §9.7.

### 16.2 Параметры

| Параметр        | Значение                          |
| --------------- | --------------------------------- |
| Стоимость       | 5⚡ (до 2⚡ с предметом «облако») |
| История         | Хранится вся, локально            |
| Очистка истории | Доступна пользователю             |
| Сеть            | Не требуется                      |

### 16.3 Обоснование применения ИИ

- Задача: ответы ребёнку на вопросы по темам веток обучения; питомец озвучивает ответ.
- Данные: только закрытый датасет (≈1000 Q&A + база знаний); персональные данные пользователя не обрабатываются и не покидают устройство.
- Контроль корректности: закрытая предметная область (содержание веток §9), датасет курируется командой вручную, свободная генерация вне заданной темы не предусмотрена.

### 16.4 Поведение вне темы

Нераспознанный или внетематический вопрос → нейтральный ответ-заглушка со ссылкой на вкладку «Уроки», без выдумывания фактов.

### 16.5 Модель данных

```
AiChatMessage { id, role: "user"|"assistant", content, energy_spent, created_at }
```

### 17.1 Вход

Барьер: 4-значный PIN, который взрослый задаёт при первом входе (хранится в SecureStore); если PIN забыт — восстановление через арифметический пример. Это согласованная замена барьера «арифметический пример или удержание кнопки», предусмотренного ТЗ.

### 17.2 Содержимое

| Раздел           | Описание                                   |
| ---------------- | ------------------------------------------ |
| Цели приложения  | Образовательные результаты                 |
| Пройденные темы  | Прогресс по веткам обучения                |
| Общий прогресс   | Уровень, опыт, достижения. **⚠** Число завершённых приключений не показывается — см. §30 |
| Сброс профиля    | Кнопка сброса к исходному состоянию: экономика, прогресс, подарки, достижения, стрик (имя и питомец сохраняются) |
| Удаление профиля | Полное удаление локальных данных (SQLite, AsyncStorage, PIN) |
| Демо-режим       | Активация/сброс демонстрационного режима   |

### 17.3 Правила

Без негативных оценок ребёнка; только позитивная/нейтральная подача; сброс и удаление — с подтверждением. Раздел для взрослого обращается на «вы».

## 18. Демо-режим

### 18.1 Назначение

Режим для экспертной проверки: обязательный сценарий (§19) проходится подряд без ожидания реального времени.

### 18.2 Требования

Цель (решение команды 28.09): весь функционал — от онбординга до повышения уровня — показывается за 1–2 минуты. Все ускорения действуют только в демо-профиле; обычная игра не меняется.

| Требование       | Реализация                                                                   |
| ---------------- | ---------------------------------------------------------------------------- |
| Тестовый профиль | Демо-профиль создаётся в онбординге или включением режима в разделе для взрослого (тогда профиль сбрасывается к исходному состоянию) |
| Приключения      | Завершаются в любой момент (✕) с полной наградой; каждое демо-приключение даёт ровно столько опыта, сколько нужно до следующего уровня, — новый уровень (и облик на уровнях 2–3) после каждого |
| События          | При каждом заходе на экран приключения, через 1–2 с, без часового ритма; не больше 2 за приключение и по сценарию: сначала трата с выбором «надо/хочу», затем подарок (`demo_order` в `content/adventure_events.json`). Правило §12.3 (платный вариант — только если хватает денег) действует |
| Задания          | Любой урок открывается сразу; урок укороченный — 2 карточки теории, мини-игра целиком, 2 вопроса теста (у урока-викторины — одной пачкой с вопросами мини-игры; порог и награда те же) |
| Аркада           | Короткие раунды: «Викторина» — 3 вопроса, «Свайпы» — 3 карточки, «5 букв» — 1 слово |
| Сброс            | «Начать демо заново» — демо-профиль удаляется, онбординг открывается с уже включённым режимом |

### 18.3 Активация

Переключатель «Режим демонстрации» на первом экране онбординга (⚠ §30 п. 8) или переключатель в разделе для взрослого (§17).

### 18.4 Сценарий показа за 1–2 минуты

1. Онбординг: на первом экране включить «Режим демонстрации», пройти шаги
   (тур по комнате можно пропустить), выбрать первую цель — около 30 с.
2. Хаб → «Начать приключение»: распределить бюджет на «Потратить» и «Коплю»,
   выбрать тему — около 10 с.
3. Экран приключения: через 1–2 с — событие «Захотелось перекусить» (выбор
   «надо» или «хочу», трата из бюджета приключения).
4. «Выполнить задание» — укороченный урок: 2 карточки теории, затем одной
   пачкой вопрос мини-игры и 2 вопроса теста, награда — около 20 с.
5. Возврат к приключению — второе событие, «Неожиданный подарок».
6. Кнопка Аркады — по очереди «Викторина» (3 вопроса), «Свайпы» (3 карточки),
   «5 букв» (1 слово с подсказкой) — около 40 с.
7. ✕ → «Завершить» — итоги на хабе: план и факт, выплата в кошелёк и банк,
   новый уровень и новый облик питомца.

## 30. Не закрыто в этой версии

Ожидается в следующем документе: полный контент уроков по веткам; материалы презентации; пакет сопроводительной документации; порядок сдачи решения.

Отступления от ТЗ Департамента и открытые пункты — зафиксированы, а не решены молча:

1. **Визуальные комбинации питомца (§4.3, §20).** 7 вместо 9: для мишки нет арта и товаров-скинов вариантов 1–2 (отложено до появления арта); из-за этого мишка не получает скин на уровнях 2–3.
2. **Сравнение плана с фактом (§7.4).** В итогах есть план и факт по направлениям, но нет колонки «разница» и комментария питомца.
3. **Состояния питомца и подсказка о еде (§6.4, §8.1).** 2 визуальных состояния вместо 4; отдельной подсказки на главном экране «питомец голоден — купи еду» нет (ограничение «еда только голодному» реализовано).
4. **Раздел для взрослого (§17.2).** Не показывается число завершённых приключений.
5. **ИИ-помощник (§16.1).** Работает на заглушке; локальная модель и датасет — следующий этап.
6. **Товары «облако» и «уют» (§12.2).** Эффекты рассчитываются, товаров в каталоге нет.
7. **Барьер раздела для взрослого (§17.1).** PIN вместо арифметического примера — согласованное отступление (пример используется для восстановления PIN).
8. **Активация демо-режима (§18.3).** По решению команды (28.09) демо включается не только в разделе для взрослого, но и переключателем на первом экране онбординга — чтобы показ за 1–2 минуты начинался с онбординга и без PIN. Ускорения демо (события сразу, укороченные урок и раунды Аркады, уровень за приключение, §18.2) действуют только в демо-профиле.
9. **Распределение «надо / хочу / коплю» (§7.3, §19 п. 5).** По решению команды (27.09) на планировании только «Потратить» и «Коплю»; «надо» и «хочу» видны в факте трат событий и в итогах, но не планируются. Риск для приёмки по §19 п. 5 — при необходимости вернуть поле «Надо/Хочу» внутри «Потратить».
10. **Доступность тренажёров (§10.2).** Ранее — только полностью пройденные темы со случайным выбором темы; по решению команды (27.09) Аркада даёт любую мини-игру по теме текущего приключения, в том числе до прохождения всех уроков темы. Вопросы берутся из уроков этой темы.
11. **Экран ИИ-помощника (§16).** По решению команды (27.09) вкладка ИИ-помощника временно заменена вкладкой «Копилка»; экран, списание энергии и история остались в коде, но из интерфейса сейчас недоступны. Для приёмки по §16 вкладку нужно вернуть (одна строка в `(tabs)/_layout.tsx` и `constants/mainTabs.ts`).
12. **Мини-игра в уроках-викторинах (§9.1).** По решению команды (28.09) у урока с мини-игрой «Викторина» её вопросы идут в одной пачке с тестом (раньше — два одинаковых по виду шага подряд: «Вопрос 1 из 1», затем «Вопрос 1 из 5»). Награда за фазу мини-игры сохранена; вопросы мини-игры проверяются общим порогом теста (70%), а не «до верного ответа». Уроки со «Свайпами» и «5 букв» — без изменений.
